# ygopro-hollow-deckbuilder

把「遊戯王ニューロン」匯出的牌組截圖，轉換成可以匯入 YGOPro（ver.1.035.4 hollow 版）模擬器的
`.ydk` 檔案。純本地圖片比對，不使用文字 OCR，也不連網路。

---

## 中文說明

### 需求
- Python 3.10+
- 本機已安裝 `ygopro ver.1.035.4 hollow`（辨識時會即時讀取裡面的 `cards.cdb` 和 `pics/`
  圖片，卡片資料永遠是最新的，這個 repo 本身不內建任何卡表或卡圖）

### 安裝
```
cd ygopro-hollow-deckbuilder
pip install -r requirements.txt
```

如果這台電腦的模擬器不是裝在預設路徑 `H:\YGOPro\ygopro ver.1.035.4 hollow`，啟動前先設定環境變數：

```powershell
$env:YGOPRO_DIR = "D:\Games\ygopro ver.1.035.4 hollow"
```

### 啟動
```
python app.py
```
開啟瀏覽器 http://127.0.0.1:5151

### 使用方式
1. 左上角上傳 Neuron 匯出的牌組截圖（main / extra / side 三個分區）。
2. 欄數、列數留空即可自動偵測；若自動偵測漏掉最後幾列，可在「列數覆寫」手動指定每個分區的列數。
3. 按「分析圖片」。第一次執行會先對 `pics/` 建立圖片雜湊快取（約 15000 張圖，需 20 秒~2 分鐘），
   之後就是秒開。
4. 右側列出辨識結果：每格卡圖、分類（一般/效果/融合/連接...）、前三個候選卡（附距離值
   `d=`，數字越小代表越相似；`d` 超過約 35~40 建議人工確認)，也可以直接在「手動指定卡號」欄位
   輸入正確的卡片 ID 覆蓋。
5. 確認無誤後，在左下輸入牌組名稱，按「寫出 .ydk 到 deck 資料夾」，檔案會直接寫到
   `<YGOPRO_DIR>\deck\<牌組名稱>.ydk`，可立即在模擬器裡選用。

### 卡片資料更新後
遊戲更新、`pics/` 多了新卡片時，按介面上的「重建圖片快取」即可（會重新掃描整個 `pics/`，
不需要手動刪除 `cache/` 資料夾）。

### 多台電腦共用
這個 repo 不含任何卡圖或卡表，所有卡片資料都在執行時從本機的 `ygopro ver.1.035.4 hollow`
讀取。只要每台電腦都裝好模擬器、路徑透過 `YGOPRO_DIR` 對好，clone 下來就能直接用；`cache/`
內的圖片雜湊快取不會上傳，每台電腦第一次執行時會各自建立。

## 日本語説明

### 必要環境
- Python 3.10 以上
- ローカルに `ygopro ver.1.035.4 hollow` がインストール済みであること（認識時に中の
  `cards.cdb` と `pics/` 画像をその場で読み込むため、カードデータは常に最新。このリポジトリ
  自体にはカードリストやカード画像を含みません）

### インストール
```
cd ygopro-hollow-deckbuilder
pip install -r requirements.txt
```

このPCのシミュレーターのインストール先がデフォルトパス `H:\YGOPro\ygopro ver.1.035.4 hollow`
と異なる場合は、起動前に環境変数を設定してください。

```powershell
$env:YGOPRO_DIR = "D:\Games\ygopro ver.1.035.4 hollow"
```

### 起動
```
python app.py
```
ブラウザで http://127.0.0.1:5151 を開きます。

### 使い方
1. 左上からニューロンのデッキレシピ画像（メイン / エクストラ / サイドの3区画）をアップロード
   します。
2. 列数・行数は空欄のままで自動検出されます。最後の数行が検出漏れした場合は「列數覆寫」で
   各区画の行数を手動指定できます。
3. 「分析圖片」ボタンを押します。初回実行時は `pics/` の画像ハッシュキャッシュを作成するため
   （約15000枚、20秒~2分程度）時間がかかりますが、以降は高速です。
4. 右側に認識結果が表示されます。各マスのカード画像、分類（通常/効果/融合/リンクなど）、
   候補上位3件（距離値 `d=` 付き、数値が小さいほど類似度が高い。`d` が35~40を超える場合は
   手動確認推奨）が出るので、違っていれば「手動指定卡號」欄に正しいカードIDを直接入力して
   上書きできます。
5. 確認が終わったら左下にデッキ名を入力し、「寫出 .ydk 到 deck 資料夾」を押すと
   `<YGOPRO_DIR>\deck\<デッキ名>.ydk` に直接書き出され、シミュレーターですぐに選択できます。

### カードデータ更新後
ゲームアップデートで `pics/` に新しいカードが追加された場合は、画面上の「重建圖片快取」
ボタンを押すだけで大丈夫です（`pics/` 全体を再スキャンするので、`cache/` フォルダを手動で
削除する必要はありません）。

### 複数PCでの共用について
このリポジトリにはカード画像やカードリストは含まれていません。カードデータは実行時に
ローカルの `ygopro ver.1.035.4 hollow` から読み込まれます。各PCにシミュレーターがインストール
されていて、必要なら `YGOPRO_DIR` でパスを合わせておけば、clone するだけでそのまま使えます。
`cache/` 内の画像ハッシュキャッシュはリポジトリに含まれないため、各PCで初回実行時にそれぞれ
作成されます。
